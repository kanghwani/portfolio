# v2 「살아있는 도시」 계획 (2026-08-27)

> v1(사용자 매뉴얼, `/index.html`)은 **그대로 유지**한다. v2는 `/v2/`에서 독립 버전으로 자라고,
> 완성 판정 후에만 v1과 교체를 논의한다. 작업 중에는 `noindex` + v1에서 링크하지 않는다.

## 컨셉

포폴 상단에서 픽셀 도시가 실제로 돌아간다 — 차량은 장식이 아니라 **부하 적립 라우팅(HILT)으로 움직인다**.
스크롤을 내리면 도시에 밤이 오고, 마지막 섹션에서 **집에 도착한다** (PARRYWAY 엔딩 모티프).

## 원칙

1. **정보를 게임 뒤에 잠그지 않는다** — 캔버스는 배경 레이어. 본문 HTML은 캔버스 없이도 완결 (인사담당자 20초 룰)
2. **런타임 의존성 0** — Canvas 2D + 스크롤 진행도. "포폴 배경도 제 게임 코드"가 사실이 되게
3. **폴백** — `prefers-reduced-motion`·저사양이면 정적 렌더. 실패해도 텍스트 포폴로 동작

## 스크롤 ↔ 씬

| 섹션 | 도시 상태 |
|---|---|
| 소개 + 브랜딩 | 낮, 차량 라우팅 흐름 |
| AI와 일하는 방식 | 계획→구현→검증 미니 오버레이 |
| IDLE CITY | 교차로 줌인, w=0/w=2 라이브 토글 |
| PARRYWAY | 밤 전환, 왕 캐릭터 달림 |
| 연락처 | 집 도착, 창에 불 |

## 단계 (각각 독립 배포 가능)

- **P0** ✅ 이 커밋 — 확정 문안으로 v2 스캐폴드 (AI와 일하는 방식 3항 + PARRYWAY 섹션 + IDLE CITY 요약)
- **P1 그레이박스 (1일 게이트)** — 사각형 차량+도로 라우팅 배경 프로토. **"배경으로 눈길을 끄는가" 판정. 아니면 중단하고 P0만 유지**
- **P2** — CC0 픽셀 타일셋 + 스크롤 씬 전환 (디자인 폴리시는 이 단계에서)
- **P3** — 밤낮 · PARRYWAY 구역 · 집 도착 연출
